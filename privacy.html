Store Runner

Politique de confidentialité

Dernière mise à jour : 12 septembre 2026.

Cette politique explique comment Store Runner traite les données utilisées par l’application, notamment les données obtenues via les API Google ainsi que les informations de localisation utilisées pour préparer les tournées.

Principe essentiel : la connexion Google Agenda est facultative et en lecture seule. Store Runner n’écrit aucun événement dans Google Agenda.

1. Données Google auxquelles Store Runner accède

Lorsqu’un utilisateur connecte Google Agenda, Store Runner peut lire la liste des agendas auxquels cet utilisateur est abonné ainsi que les événements accessibles dans ces agendas pour la période de planning consultée.

Pour son fonctionnement, l’application utilise notamment le nom ou l’identifiant de l’agenda, le titre de l’événement, sa localisation, ses dates et heures de début et de fin, son caractère « toute la journée » et son statut d’annulation.

2. Finalité de cet accès

Ces informations servent uniquement à aider l’utilisateur à organiser ses tournées : détecter les rendez-vous, formations, déplacements, hébergements ou autres indisponibilités, éviter les conflits horaires et présenter le planning pertinent dans Store Runner.

Store Runner ne vend pas les données Google, ne les utilise pas à des fins publicitaires et ne les utilise pas pour établir un profil marketing.

3. Stockage et transmission

  • Le jeton OAuth Google est conservé uniquement dans sessionStorage pendant la session du navigateur.
  • Le jeton OAuth n’est pas inclus dans les sauvegardes ou exports de Store Runner.
  • Les événements Google importés peuvent être conservés localement dans les données de l’application afin de préserver le dernier état synchronisé et peuvent donc apparaître dans une sauvegarde locale/exportée déclenchée par l’utilisateur.
  • Les appels Google Agenda sont effectués directement depuis le navigateur vers les API Google.
  • Les détails des événements Google Agenda ne sont pas envoyés à l’assistant IA en ligne de Store Runner.

4. Suppression et déconnexion

L’utilisateur peut déconnecter Google Agenda depuis Store Runner. Cette action révoque le jeton OAuth lorsqu’il est disponible, supprime le jeton de la session et retire de l’état courant de l’application les événements importés depuis Google.

L’utilisateur peut aussi supprimer les données locales de Store Runner depuis les fonctions de gestion des données de l’application ou via les réglages de son navigateur.

5. Assistant IA

Store Runner peut proposer un assistant IA en ligne pour des fonctions d’aide générale au planning. Par conception, le contexte envoyé à cet assistant exclut les détails issus de Google Agenda. Les réponses qui nécessitent le contenu de l’agenda sont traitées localement dans l’application lorsque cette fonctionnalité est disponible.

6. Localisation et géocodage OpenStreetMap / Nominatim

Lorsque l’utilisateur choisit « Utiliser ma position actuelle », Store Runner peut utiliser les coordonnées GPS fournies par le navigateur. Lorsque l’utilisateur recherche manuellement une ville ou une adresse de départ, le texte saisi peut être utilisé pour obtenir des coordonnées géographiques.

Pour convertir une adresse en coordonnées, ou des coordonnées en adresse lisible, Store Runner envoie directement depuis le navigateur la requête nécessaire au service public Nominatim exploité pour OpenStreetMap. Selon l’action demandée, cette requête contient soit la ville ou l’adresse saisie par l’utilisateur, soit les coordonnées latitude/longitude obtenues depuis son appareil.

Ces données sont envoyées uniquement pour déterminer le point de départ utilisé par le planning. Les événements Google Agenda et leur contenu ne sont jamais envoyés à Nominatim. Store Runner limite et sérialise ses appels au service afin de respecter sa politique d’utilisation.

Les données OpenStreetMap sont attribuées à © OpenStreetMap contributors. L’utilisation du service Nominatim est également soumise aux politiques de l’OpenStreetMap Foundation, notamment sa politique de confidentialité.

7. Google API Services User Data Policy

L’utilisation par Store Runner des informations reçues depuis les API Google respecte la Google API Services User Data Policy, y compris les exigences de Limited Use.

8. Sécurité

Store Runner limite l’autorisation Google à un accès en lecture seule. Aucun secret client OAuth n’est intégré dans l’application web. Le jeton d’accès est temporaire et reste dans la session du navigateur.

Les appels de géocodage sont déclenchés par une action de l’utilisateur et sont envoyés directement au fournisseur concerné depuis le navigateur ; Store Runner n’exploite pas ces requêtes pour de la publicité ou du profilage.

9. Évolutions de cette politique

Cette politique peut être mise à jour si le fonctionnement de Store Runner ou les exigences des fournisseurs utilisés évoluent. La date de mise à jour affichée en haut de la page permet d’identifier la version applicable.
