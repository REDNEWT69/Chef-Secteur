# Chef Secteur

Application de planification terrain pour chef de secteur Samsung.

## Base du projet
- Départ : Francheville (Rhône)
- Planning automatique de visites magasins
- Fonctionnement pensé pour iPhone et navigateur
- Données et historique stockés localement
- Préparation PWA / installation sur l’écran d’accueil

## Version de référence
Le projet repart de `Chef_Secteur_V4_3_FUSION_PREMIUM.html`, la version la plus récente retrouvée dans les fichiers du projet.

## Étapes en cours
1. Importer la version de référence comme `index.html`
2. Ajouter le manifeste PWA et le service worker
3. Vérifier le moteur de génération de semaine
4. Tester les magasins, itinéraires, historique et mode terrain
5. Préparer un déploiement web propre
